## What this entry does

`main.ts` (Node 22+) writes exactly one six-word story to `/output/entry.txt`.
The program is deterministic, uses no network, and has no dependencies — it
only creates `/output` if missing and writes the story as UTF-8 text.

## How to run

```sh
node main.ts
cat /output/entry.txt
```
